## 1. 版本定位

内测 v1.0 是一个**可本地运行的旅行路线规划原型**，面向「只听说过景点名字、不知道游玩顺序」的用户：

| 能力层级 | 是否需要 LLM | 说明 |
|----------|--------------|------|
| 地图标点 | 否 | 按用户输入顺序在 Google 地图上标 1、2、3… |
| 景点位置参考 | 否 | 标点后展示具体地址与经纬度 |
| 智能路书规划 | 是 | Agent 调用 LLM + Google Maps 工具，输出完整路书 |

**决策层是 LLM**：顺序规划、景点介绍、路书撰写、注意事项均由模型完成；Google Maps 提供真实地理约束。

## 2. 功能范围（已交付）

### 2.1 目的地与景点输入

- 目标国家 / 目标城市：并排纯文本输入；
- 景点列表：网格形式，默认一行，`+ 添加景点` 增行，支持景点名 + 可选地址；
- 已移除「自动规划行程」本地规则按钮（避免无 LLM 时产生误导性行程）。

### 2.2 地图能力（仅 Google Maps API）

- 连接 Google 地图后，点击 **「在地图上标点」**；
- 按输入顺序地理编码并打编号标记（修复了仅用城市地址导致标点重叠的 bug）；
- 标点后于「已解析景点」展示：查询串、具体位置、经纬度；
- Agent 规划后：按推荐顺序绘制路线（Geocoding + Directions）；
- 地图选点扩展切口保留，默认关闭（`featureFlags.mapPickEntryEnabled`）。

### 2.3 LLM 能力

- 默认供应商：**通义千问（DashScope）** OpenAI 兼容接口；
- 支持 OpenAI / Qwen / DeepSeek / OpenRouter 等（Base URL 自动识别）；
- 「先用 LLM 分析景点时长」：前端直连，输出景点速览与时长建议；
- 提示词定义见 `llm.js`：`buildAgentSystemPrompt`、`buildAgentUserPrompt`。

### 2.4 Agent 智能路书（核心）

`POST /api/agent/plan` 流程：

1. LLM 汇总用户全部景点；
2. 调用工具 `geocode_place`、`get_travel_time` 获取真实位置与车程；
3. 按 **「尽量不走回头路」** 策略确定游览顺序（须在 `routeStrategy` 中解释）；
4. 输出智能路书（时间段描述，不精确到几点几分）；
5. 输出目的地 **注意事项**（地形、气候、安全、文化等）。

右侧 **「智能路书」** 展示模块：

- 行程概述（`summary`）
- 路线策略（`routeStrategy`）
- 景点速览（`placeSpotlights`：介绍、看点、建议停留）
- 推荐游览路书（`roadbook`：每站游玩时间 + 前往下一站路程范围）
- 注意事项（`precautions`）

## 4. 核心接口

### 4.1 Agent 规划

- **路径**：`POST /api/agent/plan`
- **请求**：
  - `country`, `city`, `totalDays`, `visitMinutes`
  - `places[]`（`name`, `address`, `addressExtra`, `geocodeQuery` 等）
  - `llmBaseUrl`, `llmApiKey`, `llmModel`
  - `mapsApiKey`
- **响应**：
  - `summary`, `routeStrategy`
  - `placeSpotlights[]`, `roadbook[]`, `precautions[]`
  - `recommendedOrder[]`
  - `enrichedPlaces[]`, `planData[]`（供地图路线渲染）

### 4.2 Google Maps 工具（Agent 内部）

| 工具 | 用途 |
|------|------|
| `geocode_place` | 景点名 + 城市 + 国家 → 经纬度 |
| `get_travel_time` | 两景点间真实驾驶时长与距离 |

### 4.3 需启用的 Google API

- Maps JavaScript API
- Geocoding API
- Directions API

## 5. 运行与验证

### 5.1 启动

```bash
node server.js
```

浏览器打开：`http://127.0.0.1:8080/index.html`

### 5.2 推荐内测流程

1. 填写国家、城市、景点（网格）；
2. 填写 Google Maps API Key → 连接地图 → **在地图上标点**（验证无 LLM 链路）；
3. 填写通义千问 API Key（默认 Base URL 已配置）；
4. 点击 **Agent 智能规划** → 查看右侧智能路书 + 地图路线。

### 5.3 测试

```bash
node --test tests/planner.test.js tests/llm.test.js tests/agent-planner.test.js tests/location-data.test.js
```

内测 v1.0 锁定时应为 **18/18** 通过。

## 6. 已知限制（内测 v1.0）

- LLM API Key 仍由前端传入后端，内测环境可接受，生产需后端代理与鉴权；
- 路书时间为范围描述，未与日历/精确时刻表打通；
- 规划策略仅固化「尽量不走回头路」，预算/偏好/体力等策略待后续版本；
- 模型「攻略知识」依赖训练数据，未接入实时网页检索；
- 默认交通方式为驾车，未做多模式策略切换；
- 工具调用失败时依赖模型自行保守估计，重试策略较基础。
